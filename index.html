Mes Projets

De l'analyse statistique à l'algorithmique et au machine learning

01

Prédiction Prix Immobilier Paris

Python Machine Learning Streamlit

Application web interactive utilisant l'intelligence artificielle pour estimer le prix des biens immobiliers à Paris. Le modèle prend en compte la proximité des stations de métro, les caractéristiques du bien et fournit une estimation précise basée sur un algorithme d'apprentissage automatique entraîné sur des données réelles du marché parisien.

🚀 Testez l'application en ligne :

Essayer l'estimateur →
  • Interface intuitive avec sélection de station de métro et curseurs interactifs
  • Visualisation des estimations avec métriques de performance du modèle (Précision: 94.8%)
  • Déploiement cloud avec Streamlit pour un accès instantané
Python Streamlit Scikit-learn Pandas Random Forest Machine Learning
02

Analyse Immobilier & Éoliennes

Économétrie Cartographie

Projet d'économétrie avancée analysant l'impact de la proximité des éoliennes sur les prix de l'immobilier. Utilisation de modèles de régression linéaire multiple et création de cartes géospatiales interactives pour visualiser les corrélations distance-prix.

  • Modélisation statistique avec régression linéaire multiple sous R (R² = 0.787)
  • Cartographie interactive avec QGIS montrant les variations de prix par zone
  • Analyse spatiale de corrélation entre distance aux éoliennes et valeurs immobilières
R QGIS Économétrie Régression Linéaire Analyse Spatiale
03

Matières Premières Critiques : Le Lithium

Recherche scientifique Data Analysis

Projet de recherche scientifique sur les enjeux géopolitiques et économiques de l'accès aux matières premières critiques, avec focus sur le lithium. Analyse statistique complète de la production mondiale et rapport académique de 20 pages.

  • Analyse de données internationales (production, réserves, parts de marché)
  • Création de visualisations : cartes mondiales, HHI, ACP, volatilité pays
  • Modélisation de la concentration de marché et croissance de production
R tidyverse ggplot2 ACP Recherche
04

Matching Politique par Votes

Algorithmique Python

Programme en Python qui analyse les votes de l'Assemblée Nationale française pour créer un système de matching politique. L'utilisateur répond à un QCM sur 10 lois et l'algorithme identifie le député dont les votes sont les plus similaires.

  • QCM interactif sur 10 lois françaises (pour/contre/abstention)
  • Algorithme de matching basé sur la similarité cosinus entre votes
  • Traitement de données Excel (liste des députés + historique complet des votes)
Python Pandas Algorithmes Analyse de données Matching
